# Assets Directory

This directory should contain the following app assets:

## Required Files

- `icon.png` - App icon (1024x1024 recommended)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon (foreground)
- `favicon.png` - Web favicon

## Temporary Solution

For development, you can use placeholder images or Expo will use default assets.

## Generating Assets

You can use online tools or design software to create these assets:
- Icon: Should be a square image representing your app
- Splash: Can be a logo or branded image
- Adaptive icon: Android-specific, should work with different shapes

Once you have the assets, place them in this directory and the app will use them automatically.
